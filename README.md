# Kathiyawad Ice Cream

A modern, interactive web application for **Kathiyawad Ice Cream** crafted with React, Vite, Tailwind CSS, and Framer Motion.

## Features

- **Flavors & Scoops**: Interactive ice cream scoop builder with authentic flavors (Pistachio, Alphonso Mango, Rajbhog, Berry Blast, Meetha Mawa, etc.).
- **Smooth Animations**: Smooth scrolling with Lenis and interactive transitions using Framer Motion.
- **Carousel & Deals**: Featured bundles, date night combos, and family tubs showcased via Swiper.
- **Parlour Finder**: Direct parlour contact details and location directory.
- **Responsive Design**: Polished, mobile-first design.

## Tech Stack

- **React 19**
- **Vite 8**
- **Tailwind CSS v4**
- **Framer Motion**
- **Lenis**
- **Swiper**
- **Lucide Icons**

## Getting Started

### Installation

```bash
# Using pnpm
pnpm install

# Or using npm
npm install
```

### Running Locally

```bash
pnpm dev
# or
npm run dev
```

### Building for Production

```bash
pnpm build
# or
npm run build
```
